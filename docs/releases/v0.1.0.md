First alpha desktop release of Universal Creative Software Hub.

## Included
- Curated creative-software discovery, Creative Top 50 and ArtCraft Suite filters.
- Personal library, favorites, local private shortcuts and on-demand installed-app scanning.
- Downloads dashboard with progress and explicit installation confirmation for reviewed adapters.
- Ed25519-verified ArtCraft catalog synchronization.
- Public GitHub project tracking and manual release checks.
- Community application requests, duplicate detection, moderator review and approved catalog refresh, including the reviewed BIMCraft download/install integration.

## Downloads
- **Fedora 45 x86_64:** `.rpm`, unsigned. Verify its SHA-256 against `SHA256SUMS.txt`, then install this local package with `sudo dnf install --nogpgcheck ./<downloaded-file>.rpm`. Fedora 45 requires this explicit exception for unsigned packages; it applies only to that invocation, not a permanent system setting. Older Fedora versions are not verified.
- **Windows x64:** NSIS `.exe` installer. Unsigned; Windows may display an unknown-publisher/SmartScreen prompt. WebView2 is required; the installer handles its bootstrap when needed.
- **macOS Apple Silicon:** `.dmg`. The app is ad-hoc signed, not Apple Developer ID signed or notarized; Gatekeeper may require explicit approval in Privacy & Security. Intel Macs are not covered by this release.
- **SHA256SUMS.txt:** SHA-256 checksums for all three installers.

Only packages produced by the successful release workflow are uploaded. Checks include frontend/catalog/browser regression tests, Rust unit tests on all three build hosts, native packaging, RPM installation/dependency resolution on Fedora, Windows archive integrity/PE architecture, macOS disk-image integrity/code-signature/version/architecture, and a checksum-verified download of the uploaded assets before publication. These are automated build/package checks, not a claim of interactive testing on end-user desktops.

## Alpha limitations
Native installation support varies by app/platform and always requires confirmation. Unreviewed GitHub downloads are not automatically executed. Private shortcuts are stored locally, not encrypted. Third-party automatic upgrades are not implemented; tracked GitHub release differences do not prove an installed app is outdated. Publisher downloads require network access and remain subject to upstream availability and licensing. Android, Linux AppImage, Windows ARM and macOS Intel packages are not included.
